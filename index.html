🏋️ Shred, coach sportif et nutrition

Application installable (PWA) pour suivre ses séances et ses repas, avec série quotidienne, rappels push et coach IA qui connaît ton programme.

Code Démo

Description Détaillée

Les notifications Web Push sont codées sans dépendance (VAPID, aes128gcm). Le coach s'appuie sur une recherche BM25 locale dans l'historique et n'envoie au modèle que les extraits utiles. 🖼️ Légendage automatique d'images (CESI)

Description Détaillée

📊 Visualisation des Données de Vente
